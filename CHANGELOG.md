# Changelog

## 0.0.1 — 2026-11-07

Primeira release do MVP local (sideload; sem Play Store).

### Destaques
- Captura de notificações **Nubank** e **Santander** → sugestões de despesa
- Janela **Registrar despesa?** sobre a tela (mesmo com o app fechado)
- Confirmação com caixas de seleção de **conta/cartão** e **categoria** (pré-seleção a partir da notificação: débito/crédito/Pix)
- Home guia do mês: **Caixa · Pendentes · Faturas · Livre**
- Abas Home / Relatórios / Config; contas e cartões; categorias com 1 nível de subcategoria
- Simulador de notificações (APK debug)

### Assinatura
APK release deste tag assinado com a **keystore debug** do Android (MVP sem secrets no repositório). Para distribuição própria, use uma keystore local conforme o README.
